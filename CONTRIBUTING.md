# Contributing

Thank you for improving FormStorm Lab.

1. Use Node.js 22 or newer.
2. Create a focused branch and add tests for behavior changes.
3. Run `npm ci` and `npm run verify`.
4. Do not use real credentials, production form data, or unapproved live targets in fixtures.
5. Open a pull request that explains the user impact and verification performed.

Bug reports should include the fixed seed, fixture or allowlisted origin, minimal replay case, and redacted logs.
