# Security Policy

## Supported version

Security fixes are provided for the latest `0.1.x` release line.

## Reporting

Please use GitHub private vulnerability reporting. Do not open a public issue containing credentials, cookies, private form values, or a live target that was tested without authorization.

## Project boundary

FormStorm Lab is a QA tool for systems you own or are authorized to test. The default workflow uses deterministic local fixtures. External targets require an exact origin allowlist, and state-changing network requests are blocked by default.
